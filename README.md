# Jiva Gym — Página web

Página web de **Jiva Gym** (La Chorrera, Panamá): planes, beneficios, tienda (Coffee, Suplementos, Merch), horario y ubicación, y pase de prueba gratis con código QR.

Es un sitio estático (HTML, CSS y JavaScript, sin dependencias que instalar), listo para publicarse en Cloudflare Pages, Netlify o GitHub Pages.

## Estructura

```
index.html          Página principal
css/styles.css      Estilos
js/main.js          Animaciones, pase de prueba y efectos de scroll
assets/logo/        Logo de Jiva Gym (SVG y PNG de 3000 px)
assets/img/         Texturas de fondo
```

## Ver en local

Abre `index.html` en el navegador.

## Pendiente antes de publicar

- Número de WhatsApp real de Jiva en los botones (hoy abren WhatsApp sin contacto).
- Fotos reales: tira "Esto es Jiva", tarjetas de "Entrena en Jiva Gym", foto del local y productos de la tienda.
- Videos cortos para las tarjetas de "Entrena en Jiva Gym" (se reproducen al pasar el cursor; van en el atributo `data-video`).
- Mapa real de Google Maps en la sección de ubicación.
- Confirmar dirección y horario con el dueño.
